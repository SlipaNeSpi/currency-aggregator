# Агрегатор курсов валют

Система сбора, нормализации и отображения курсов валют из нескольких источников (ЦБ РФ, Т-Банк).

## Архитектура
- **parser** – Python-сервис сбора и нормализации.
- **PostgreSQL** – основная БД.
- **pgAdmin** – администрирование БД.
- **Metabase** – визуализация и дашборды.
- **web** – Flask-приложение для просмотра курсов.
- **nginx** – reverse proxy.
- **GitHub Actions** – CI.
